# Slothlet Vine v1.1.2 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A dependency patch. No runtime source changed — the forwarding core, wire protocol, event forwarding, and every transport are untouched. The one consumer-visible change is a higher `@cldmv/slothlet` peer floor: `>=3.14.0` → `>=3.20.0`.

---

## 🔧 Dependencies

- **`@cldmv/slothlet` peer floor raised to `>=3.20.0`, dev pin to `^3.20.0`** (#31). Previously the peer floor was `>=3.14.0` and the dev pin `^3.18.1`. The test suite now runs against 3.20.0, so that is the version the floor guarantees.
- **Patch group** (#30, lockfile only): `@cldmv/eslint-plugin-jsonv` `1.0.3` → `1.0.10`, `@cldmv/jsonv` `1.0.2` → `1.0.9`, `@cldmv/prettier-plugin-jsonv` `1.0.1` → `1.0.6`. Dev tooling only.
- **`prettier`** `3.9.6` → `3.9.8` (#27) and **`vitest`** `5.0.0` → `5.0.1` (#26). Dev tooling only.

---

## Upgrade notes

Consumers must be on `@cldmv/slothlet` `>=3.20.0`; a lower version now produces a peer-dependency warning (or an install error under strict peer resolution). Nothing else to do — no API, protocol, or behavior changes.
