# Slothlet Vine v1.2.2 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A single dev-tooling dependency patch. `@cldmv/fix-headers`, which maintains the comment headers at the top of the repository's source, test and config files, moves from 2.1.1 to 2.1.4. No runtime source changed: the forwarding core, wire protocol, channel principal, `around`, event forwarding and every transport are exactly as in v1.2.1, and both peer ranges are unchanged (`@cldmv/slothlet >=3.22.0`, optional `ws >=8.0.0`).

The bump was made with a header restamp in mind, but fix-headers 2.1.4 produced no header changes in this repository, so the only files touched are `package.json` and `package-lock.json`.

---

## 🔧 Dependencies

- **`@cldmv/fix-headers` `2.1.1` → `2.1.4`** ([#72](https://github.com/CLDMV/slothlet-vine/pull/72)), dev dependency. The 2.1.x line no longer stamps a header into files that have no usable comment syntax (strict JSON such as `package.json`, and Markdown unless explicitly forced), never walks into `node_modules` or other dependency folders, and processes every repeated `--input` value instead of only the last. It only runs through the `fix:headers` script; nothing in the published package depends on it.
