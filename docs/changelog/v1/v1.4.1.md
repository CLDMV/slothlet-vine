# Slothlet Vine v1.4.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

v1.4.1 lowers `engines.node` from `>=22.22.0` to `>=22.15.0`. v1.4.0 set the package floor to the version its development toolchain needs, which was higher than anything the package needs at runtime. The runtime floor is now the floor of the `@cldmv/slothlet` peer, and the toolchain floor moves to npm's `devEngines`, where it only applies to working on this repository.

The vine runtime is unchanged: `grow()`, `serve()`, the transports, the error taxonomy, the frame format and the peer ranges are the same as v1.4.0.

---

## 📦 Requirements

### `engines.node` is `>=22.15.0` ([#107](https://github.com/CLDMV/slothlet-vine/pull/107))

`engines.node` drops from `>=22.22.0` to `>=22.15.0`, the floor `@cldmv/slothlet` itself declares. Both `import` and `require()` work from 22.15.0: that line already has the synchronous `require(esm)` the `.cjs` entries load the bundles through. The `ERR_REQUIRE_ESM` message each `.cjs` entry throws on a Node.js without `require(esm)` now names `>=22.15.0`.

Developing the package still needs Node.js 22.22.0 or later. That floor is now declared in `devEngines` (`runtime` `node` `>=22.22.0`, `onFail: "error"`), so npm enforces it in a checkout of this repository and never for consumers installing the package.
